# Linux Commands – File and Directory Basics

## Create a File

Create a new file on the Desktop.

```bash
cd ~/Desktop
touch file1.txt
```

## Common Linux Commands

### 1. `ls`

Lists the files and folders in the current directory.

```bash
ls
```

### 2. `pwd`

Displays the current working directory (your current location).

```bash
pwd
```

### 3. `cd`

Changes the current directory.

Example:

```bash
cd Desktop
```

### 4. `cd ..`

Moves one directory back (to the parent directory).

```bash
cd ..
```

## Create Multiple Files

```bash
touch file1.txt file2.txt file3.txt
```

## Read a File

Display the contents of a file:

```bash
cat file1.txt
```

Or view it page by page:

```bash
less file1.txt
```

## Count the Number of Files in the Current Directory

```bash
ls | wc -l
```
